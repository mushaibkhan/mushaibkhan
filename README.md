## 🗺️ Typical Production Architecture

```text
  Browser / Client
        ↓
  Cloudflare  ──────  DNS · DDoS · WAF · CDN
        ↓
  Nginx  ────────────  Reverse Proxy · SSL Termination
        ↓
  Docker Containers
   ├── Next.js / React  ──  Frontend (SSR/SSG)
   ├── Express / Node.js ── REST API
   ├── Laravel API  ──────  PHP Backend
   ├── WordPress  ────────  CMS
   ├── MySQL / PostgreSQL   Relational DB
   ├── MongoDB  ──────────  NoSQL
   ├── Redis  ────────────  Cache / Sessions
   └── Queue Workers / Cron
```
